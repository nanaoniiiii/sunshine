## 本轮行为

- 三星桌面按固件能力选择：已有原生 DeX、本机 DeX for PC、平板 Standalone DeX、Sunshine 兼容桌面。SM-T970 的 Standalone 使用主屏 Display 0，不冒充独立第二屏；S20+ 的本机 DeX 使用独立 Display 2。不能保证所有三星固件都支持原生 DeX。
- 修复兼容桌面启动到错误显示、空白系统次级桌面、控制窗被 AppOps 隐藏，以及平板 DeX 被新客户端错误自动旋转的问题。提供应用列表、最近任务、返回、快捷控制、退出桌面、通知退出与 Ctrl+Alt+Esc。
- 悬浮控制窗只在用户开启“第二屏／桌面模式”且桌面创建成功时显示；平板通过此入口打开 Standalone DeX 时同样保留退出入口。普通主屏串流、主屏息屏串流、退出、创建失败和最后一路断开后均不显示。绑定着 shell 服务本身不满足显示条件。
- 设置 → 软件更新：应用启动时自动检查，成功后 6 小时内节流；后台任务每 6 小时在网络可用时检查。系统省电与任务调度可能延后；强制停止后需重新打开。发现新发布版本发送通知，点击进入应用更新对话框。
- 更新源为本仓库 GitHub Releases，含已发布预览版；源代码 push、草稿、没有 APK 的版本不触发安装更新。按设备 ABI 选择包，没有对应包时选择 universal。
- 匿名 REST API 限流或不可达时尝试 GitHub 官方 Releases Atom 与附件列表；备用路径要求准确 SHA-256。DownloadManager 下载，应用内显示进度，完成后校验哈希（存在时）、包名、版本、versionCode 与当前签名。FileProvider 仅开放更新目录的临时读取权。
- 点击安装调起系统安装器；首次按 Android 要求允许 Sunshine 安装应用，返回后继续。无需浏览器，安装会重启应用并断开现有串流。
