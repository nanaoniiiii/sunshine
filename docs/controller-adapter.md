# 手柄、遥控器与 Sunshine 桌面

在设置底部打开“实验性功能”，可启用全局适配器、修改按键绑定或进入“手柄测试”。适配器随 Sunshine 主机服务启动，不依赖 Moonlight 串流连接。它需要 Sunshine 已获 Shizuku 授权；系统控件导航服务未连接时，实验室会显示状态和无障碍设置入口。停止主机服务或关闭适配器会释放本次接管的输入设备，只恢复 Sunshine 自己添加的无障碍项，保留其他服务。

手柄可以连接手机主机，也可以连接 Moonlight 接收端。电脑端测试时请让 Moonlight 串流窗口取得焦点；接收端没有转发的输入无法由主机补发。专用方向遥控器会按其提供的键码识别，完整键盘、鼠标和触屏不会被作为专用手柄独占接管。

## 默认操作

| 输入 | 导航模式的操作 |
| --- | --- |
| A／遥控器确定 | 触发当前控件 |
| B／遥控器返回 | Android 系统返回 |
| X | 最近任务 |
| Y | 下拉通知栏；普通第二屏使用可见的快捷控制入口 |
| 方向键／左摇杆 | 上下切换焦点层级，左右选择同层控件 |
| LB／RB | 快速切换当前位置的上级菜单；桌面下方操作区切换所属应用 |
| 右摇杆 | 触摸滑动 |
| L3（按下左摇杆） | 导航与鼠标模式之间切换 |
| R3（按下右摇杆） | 系统映射与游戏原生模式之间切换 |
| 主页 | 恢复导航并执行系统主页；普通第二屏回 Sunshine 临时主页 |
| 菜单／Start | 系统菜单键 |
| 遥控器电源 | 在主屏调用系统电源菜单，由系统确认关机；第二屏需先退出桌面回主屏 |

B 使用系统返回规则，不会因连续按下或页面无变化而强制回主页。应用若拦截了手机自身的返回，手柄 B 也遵循相同行为；可使用主页或最近任务切换离开。

## 圆环、鼠标和游戏

LT 按下达到触发阈值立即打开快捷操作圆环，RT 打开常用应用圆环。按住保持，用左、右任一摇杆选择；松开扳机执行，摇杆居中松开取消。圆环关闭后摇杆回中才恢复普通导航，避免释放时额外移动或滑动。游戏原生模式下扳机交给游戏，不唤出圆环。

RT 列表当前来自 Android 最近 7 天的应用使用记录。三星 DeepSky 建议小组件接口受系统关联权限保护，因此此列表不声称与三星原生建议列表相同。测试页和圆环会显示实际来源。

鼠标模式下左摇杆控制可见光标，A 为鼠标主键，B 为副键，支持按住和拖动；X、Y 继续执行系统操作。再次按 L3 回到导航。

游戏原生模式把 ABXY、方向、摇杆和扳机作为 Android 游戏手柄输入交给应用，R3 保留用于切回导航。主页也可恢复导航。补充逃离操作为 Start＋B 系统返回、Start＋X 最近任务、Start＋Y 通知栏；长按 Start＋Select 约一秒恢复导航并回主页。

## 桌面与自定义

开启虚拟屏默认保留手机原有内容并关闭物理面板。只有在设置→虚拟屏打开“第二屏桌面模式”后，才选择 Sunshine 或设备自带桌面。普通 Sunshine 第二屏保留临时主页，返回和主页不能直接退出；桌面明确的“退出桌面”按钮返回手机主页并保留虚拟屏、全屏与息屏串流。三星原生 DeX 保留原主页和任务栏。

Sunshine 桌面的顶部入口为应用、最近任务、控制、搜索、设置。焦点进入上级页面时立即切换，设置操作在确定后打开；上下键进入下层或返回上层。应用底部的打开、更多和退出入口也可取得焦点。最近任务使用应用图标卡片，控制页的文字选项具有独立深色衬底。

实验室可修改默认按钮或选择“录入其他按键”，录入过程只捕获按键，不执行原操作，15 秒未输入会退出。可随时恢复默认绑定。手柄测试页显示各设备模式、轴值、触发记录、系统控件导航状态与鼠标事件接收区；切换模式时也会显示当前模式提示。

控件导航依赖应用提供的 Android 无障碍控件树。自绘游戏画布等界面可切换鼠标或游戏原生模式。当前实机验证包含 Xbox 手柄、S20+ 与 Windows Moonlight，并以 OPPO 合成输入补充设置和轴兼容检查；不将这些结果扩展为所有手柄、遥控器和所有应用均已验收。具体证据见[验证记录](validation/controller-desktop-2026-10-23.md)。
