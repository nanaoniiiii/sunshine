# v2026.10.14.4：原生画布旋转与手机全屏兼容

日期：2026-10-14。此次代码修改全部位于 Sunshine，测试使用设备原有的 Moonlight 接收端。

## 手机接收端配置

1. Sunshine：设置 → 画面与流畅度 → 开启“固定画布旋转兼容”。
2. Moonlight：使用与主机匹配的竖屏分辨率，例如 1440×3168；关闭自由旋转／横竖屏自由切换，开启填充刘海区域。
3. 接收端固定为竖屏显示。阿西西版可开启“竖屏显示模式”，或在串流菜单点击“旋转屏幕”切到竖屏。
4. 主机进入横屏应用时，随画面转动接收手机；返回竖屏应用时转回。

兼容模式保持编码尺寸，通过 GL 旋转画面，并将触控、鼠标坐标反向变换。它不需要重新配对或修改 Moonlight 程序。

电脑接收端可关闭此模式，开启“自动旋转”，让编码画布直接交换宽高。

## 实机结果

- 主机：Samsung SM-G986U1，Android 13；接收端：OPPO PDEM10，Android 11，原有月光·阿西西。
- 主机临时设置为 1440×3168，与接收端原生竖屏分辨率一致；测试后恢复原显示设置。
- HEVC 请求 1440×3168、120 FPS。同一会话 `87303800225793` 完成竖屏、左横屏、右横屏、回到竖屏。
- 两个横屏方向的画面均使用完整编码视口 `[0, 0, 1440, 3168]`；编码尺寸不变，编码器重建次数为 0，无 GL surface failure。
- 在接收端点击旋转后的“设置”“首页”，主机进入对应页面，验证两个方向的实际触控。
- 桌面 Windows Moonlight 已验证 H.264 720×1280 ↔ 1280×720 的画布切换，同一会话完成三次切换。

此处“全画布”指采集内容完整填入编码画布，不改变源应用视频本身的比例；源应用、系统状态栏、导航栏和屏幕缺口仍按原样采集。
