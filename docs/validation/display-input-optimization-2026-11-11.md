# 显示恢复与触控事件优化验收

日期：2026-11-11。基线：`ddcf5b5`。发布版本：`v2026.11.11.1` / `20261047`。

## 本轮实现

### 显示恢复逐项执行

`FullscreenDisplay.restore()` 原来有两种提前结束：写入某项系统设置时抛异常，会跳过后面的恢复；前面的操作返回 false，布尔短路会跳过采集窗口同步。

现在分别尝试恢复尺寸覆盖、应用方向策略、用户旋转设置和采集窗口。任何一项失败都继续尝试其他项，最终仍返回失败，保留错误反馈。没有将部分恢复报告为全部成功，也没有更改分辨率的自然方向坐标规则。

新增回归测试分别验证尺寸写入抛异常、方向策略写入被拒绝时，其余恢复与采集同步仍被调用。

### 触控事件复用指针缓冲

原有路径在每次触控移动时创建指针列表、属性数组、坐标数组及每个指针对象。现在由 `TouchEventStaging` 复用属性与坐标暂存空间，保留指针顺序、动作索引和压力范围；Android `MotionEvent` 生成后拥有独立的数据。新增触点的 Android ID 使用已有 ID 的位集合寻找空位，避免临时集合。

事件仍按原路径注入、回收，输入目标和桌面/DeX 行为没有新增分支。测试覆盖旧事件不受后续缓冲复用影响、数量重置、全部 32 个指针编号与动作索引。32 点检查验证事件构造能力，不代表真实触摸屏支持 32 指或已完成 32 指系统注入。

### 修正引擎恢复日志

主动重启空闲引擎后，当前三星固件会结束录屏。原日志声称主机和采集都保持运行，容易误判就绪状态；现改为说明主机仍运行、采集可恢复。没有改变录屏授权或系统停止录屏后的处理策略。

## 顺序评估结果

| 方向 | 结论与处理 |
| --- | --- |
| 串流采集与引擎生命周期 | 保留现有采集所有权、代次与显示线程约束。修正恢复日志；没有在缺乏 EGL 实机证据时改写 Surface 销毁顺序。 |
| 显示设置与回滚 | 确认提前退出会阻断其他恢复，采用逐项恢复。 |

| 新系统桌面与高刷 | 现有测试机为 Android 13/11。本轮没有修改三星 DeX 或刷新率后端，没有新增解锁高刷的实测结论。 |

## S20+ 实机结果

设备：SM-G986U1 / Android 13。初始主屏物理尺寸 `1440×3200`，覆盖尺寸 `1440×2560`，自动旋转为 1、用户旋转为 0。测试后这些值和原有全屏选择均已恢复。

- 已安装最终 arm64 APK，回读安装包 SHA-256 与发布候选完全相同。
- 升级后既有开机即连、后台与录屏授权保留，服务和录屏自动就绪。未清空数据、重新配对或要求用户点击授权。
- 非法显示模式返回 HTTP 400，已有选择不变。
- 默认/全屏选择在空闲引擎重启后保留，最终恢复为测试前的 `fullscreen`。
- 空闲引擎重启后 `engineReady=true`、`captureReady=false`：该固件结束了录屏，应用报告等待下次串流恢复。不能将引擎就绪等同于录屏仍就绪。本轮未发起串流验证后续恢复。
- 测试结束重新安装相同候选包，触发既有升级恢复流程，将设备留在服务与录屏就绪的状态。
- 所有诊断采样中的 `audio.capturing` 均为 false；没有启动带音频的 Moonlight 会话。

将生产编译产物中的 `TouchEventStaging` 放入独立 ART 探针，使用 Android 实际 `MotionEvent` 检查数据复制、动作索引、编号 31、16/32 个指针及数量重置，均通过。探针没有向系统注入事件，也没有启动音频。

暂存对象微基准：预热后每种情况执行三轮，每轮 30,000 次，以下为中位数。对照仅构造指针数组和事件，不包含网络、Binder、应用消费或编码。

| 指针数 | 原构造耗时 | 复用耗时 | 原 Java 分配量 | 复用 Java 分配量 |
| --- | --- | --- | --- | --- |
| 2 | 4.425 µs/次 | 4.023 µs/次 | 225 B/次 | 低于 1 B/次计数精度 |
| 10 | 11.055 µs/次 | 11.128 µs/次 | 995 B/次 | 低于 1 B/次计数精度 |

收益是减少 Java 分配与潜在 GC 压力。10 指耗时未改善，因此不宣称全面加速、输入延迟下降或串流帧率提升。

第二台设备在本轮识别为 OPPO PDEM10 / Android 11，读到物理尺寸 `1440×3168` 和已有 Sunshine 安装；在 ART 探针部署前 USB 消失，未完成运行时检查、升级或功能验收。早先暂存的 S20 查询为空，后续确认该设备不在线，不将其计入两机通过。
