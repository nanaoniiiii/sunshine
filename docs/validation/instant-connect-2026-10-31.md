# 开机即连与录屏恢复验收（2026-10-31）

版本 `v2026.10.31.1`，versionCode `20261045`。本次实机为 SM-T970 / Android 13。

## 使用入口

设置 → 服务与启动 → **开机即连**。启用时同时保存服务自启、常驻和自动录屏，完成本应用的 PROJECT_MEDIA、后台界面启动及后台运行授权。已有的仅启动服务设置不会在升级时自动变成免确认录屏；新功能需明确启用。

启用过程可以使用现有 Shizuku 授权或已经配置好的 AppOps 权限。开机首次用户解锁后，系统广播启动前台服务；后台授权代理只取得新的录屏会话，不进入 MainActivity，也不保留最近任务。Android 10–13 才启用该免确认路径，较新系统不假定同样有效。

## 实现行为

- 引擎启动独立于 mDNS 注册，避免网络发现等待阻塞引擎和录屏准备。
- 自动初始化期间持有有超时的短时唤醒锁；取得录屏或准备结束时释放。修复实机首轮启动中三星 Freecess 在约 5 秒后冻结尚未就绪的进程的问题。
- 新启动应用和 Moonlight 恢复已有会话都检查录屏；需要时通过独立的透明授权活动重新取得会话，不要求用户进入主页。
- 录屏丢失时释放采集资源；新录屏建立后，为仍连接的客户端重新注册编码 Surface 和播放音频采集。
- Shizuku 可用时查询当前系统录屏归属，其他应用占用期间等待，结束后再准备。观察失败时不会自动接管其他录屏；冷启动有一次用户配置的初始化尝试。
- 不在系统停止回调中再次停止已失效的旧录屏令牌。用户主动结束录屏且没有其他录屏接管时，等待下次明确串流请求，不循环重新打开录屏。
- 主动停止整个服务不立即自行重开；普通回收由前台服务和原有引擎恢复机制处理。

## 实机结果

1. **最终包真实重启。** 启动后未打开 Sunshine MainActivity，未点击录屏允许，系统顶层活动为三星主页。`startOnBoot`、`keepAlive`、`instantConnect` 均为 true，引擎和录屏均就绪，系统当前录屏归属为 Sunshine。
2. **启动时序。** 最终包日志中系统 BOOT_COMPLETED 请求为 02:34:42.589，录屏就绪为 02:34:43.458。此约 0.87 秒是收到启动广播后的准备时间，不能当成整个 Android 开机时间。最终冷启动轮询约 82.5 秒后观察到就绪，包含系统启动和广播排队。
3. **启动唤醒锁释放。** 同轮记录为 02:34:42.634 acquire、02:34:43.472 release；随后服务保持可连接，没有继续持有启动锁。
4. **最终冷启动实际收图。** Windows Moonlight 直接启动 Desktop，实际看到三星主页。客户端当时显示 2560×1440 HEVC，接收、解码、渲染约 59.9 FPS；服务端该次性能快照约 60.47 FPS。该结果是实际可见串流，不只是服务端口可连接。
5. **录屏丢失后客户端重连。** 录屏为空、引擎仍运行时，仅在 Moonlight 恢复会话便重新取得录屏，随后实际收图；未操作平板的 Sunshine 主页或录屏授权按钮。已覆盖恢复会话绕过 prepareApp 的路径。
6. **其他录屏占用与释放。** 独立测试应用通过真实 MediaProjection 和 ImageReader 持有录屏。系统归属连续检查保持为测试应用；Sunshine 等待。占用时从 Moonlight 启动会返回原有 503，不接管对方会话。测试应用结束后，待机恢复测得约 1.765 秒。
7. **持续串流恢复。** 测试应用接管约 4.969 秒后结束，Sunshine 约 2.25 秒恢复，前后 Moonlight session ID 相同，性能快照约 59.73 FPS，并通过 Windows 实际画面检查。无需重新在平板确认。
8. **原有显示设置。** 重启前后主屏 override 均为竖屏坐标 1440×2560，即横屏 2560×1440。测试应用已卸载。

## 验证边界

实际验证限本机 Android 13。录屏归属检查及自动恢复需要现有 Shizuku 服务可用；首次开机录屏初始化不依赖再次打开管理器。此设备本轮开机自动恢复了已有管理器服务，但本功能没有提供通用于所有系统的 Shizuku 开机启动方法。

设备有开机密码时，凭据保护数据和普通应用服务仍依赖首次解锁。本功能不绕过锁屏，不将普通应用改成系统应用。

多屏联动的互斥机制由系统决定。共存测试使用自有临时录屏应用，不冒充已逐一完成 Microsoft 或 Samsung Flow 全套端到端连接验收。该固件在交接旧录屏时也会通知新注册的客户端停止；测试应用延后注册自身应用层停止回调，避开这条陈旧通知，并独立检查系统实际归属和 ImageReader 收图，以免把测试工具自停误判为 Sunshine 抢占。没有修改系统框架或第三方应用。
