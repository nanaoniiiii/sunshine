# 清除旧授权后的首次安装验证

设备为国行 S20+ `SM-G9860` / Android 13，测试当前主用户。使用最终 `v2026.10.23.3` / `20261040` arm64 APK，SHA-256 为 `fcf51e40bf6b6df589ef0942384a3a2b8ec5875b0c85d4f09a164f0dfbe75852`。本轮未修改功能代码，补齐此前功能候选与最终包之间的首次安装证据。

## 清理与授权起点

用户卸载 Sunshine 后，确认包已不存在、Sunshine 和 Shizuku 服务均未运行。移除了 Shizuku 配置中精确对应旧 Sunshine UID／包名的一项授权，其他四项记录保留；撤回本轮给当前管理器加的电池优化豁免，将其后台运行操作恢复为原来的 `ignore`。Sunshine 的无障碍项和电池豁免已随卸载移除，其他无障碍服务保留。

使用系统 ADB 管理接口按这台电脑公钥的精确指纹撤销信任：撤销前检查为存在，撤销后检查为不存在。重新连接后由用户在手机上重新允许 USB 调试，未清理其他电脑的信任记录。

重新安装后，在首次打开前清除 Sunshine 数据，排除自动恢复旧配置。此时实际状态为：

| 项目 | 初始状态 |
| --- | --- |
| Sunshine Shizuku API 权限 | `granted=false` |
| 麦克风、通知权限 | 均为 `granted=false`，没有用户授权标记 |
| `PROJECT_MEDIA` | 无操作记录，默认 `ignore` |
| `SYSTEM_ALERT_WINDOW` | 无操作记录，默认模式 |
| Sunshine／管理器电池豁免 | 均不存在 |
| Shizuku server | 未运行 |

随后通过正常系统流程允许音频、通知和屏幕录制。按 Shizuku 管理器生成的官方 `start.sh` 以 USB 方式启动服务，回 Sunshine 点击远程控制设置，实际出现“要允许 Sunshine 使用 Shizuku 吗？”及“始终允许／拒绝”对话框。允许前再次确认该权限为 false、管理器后台仍为 ignore；点击“始终允许”后，Sunshine 自动将管理器后台改为 allow，管理器和自身加入电池豁免，新的输入服务与系统导航在零 Moonlight 客户端时就绪。

没有从电脑使用 `pm grant` 或给 Sunshine 设置 AppOps、开启无障碍／电池豁免来预先补权；授权后这些准备来自应用自己的已授权流程。

## 首次创建与实际接收

重新配对电脑 Moonlight，以 2560×1440 / 60fps 请求连接。正常设置页面确认“第二屏桌面模式”初始关闭；打开后显示 Sunshine 与设备自带桌面两个选项，默认选中 Sunshine。

| 测试 | 结果 |
| --- | --- |
| 首次原生 DeX | 在应用设置选设备自带桌面，主页点击开启虚拟屏，完成三星“Sunshine Local DeX／立即开始”确认。系统进入双屏 DeX，电脑 Moonlight 实际显示三星主页、图标和原生任务栏。Display 2 物理模式 1920×1080、逻辑 Override 2560×1440，编码输出 2560×1440。 |
| Sunshine 普通虚拟桌面 | 使用应用配置／创建接口切换同一运行逻辑，成功创建 2560×1440 / 60Hz 的独立桌面。Moonlight 实际显示应用图标列表和右侧背景；首次 Android 全屏提示仍会出现。本项确认创建和实际画面，不作为实体手柄操作该系统提示的验收。 |
| 默认主屏息屏 | 关闭桌面模式后创建，仍为主屏 Display 0；SurfaceFlinger 物理面板 Off，Moonlight 继续显示手机原主屏内容。 |

接收端第一次抓图抓到了背景窗口，激活正确的 Moonlight 窗口后重新观察到实际 DeX；没有将错误截图作为成功证据。静止 DeX 样本约 4fps，普通桌面加载完成样本约 60fps，均不扩展为持续帧率性能保证。

## 附加测试与清理

附加锁屏测试中，发送睡眠键后实际 `Keyguard showing=false`、后续为 Awake，未建立锁屏前提；随后一轮 DeX 启动未完成目标选择／系统确认而等待超时。该样本不作为锁屏前置检查通过，也不混同为 Shizuku 授权或用户服务绑定失败。最终包的这一新增锁屏检查仍未完成独立实机验收。

退出 DeX 后宿主曾以三星弹出窗口显示，该系统窗口状态没有作为授权失败处理。测试截图与设备日志均只保留在本地忽略目录，不公开设备主页、通知、指纹或配对内容。

测试连接已结束，虚拟屏和本地 DeX 接收端已清理，主屏恢复原 `1080×2400` override、全局强制桌面值 `1`，USB 保持亮屏值为原 `0`。配置恢复默认 `screen_off / sunshine`，服务与输入适配器在无客户端时保持就绪。清理了 ADB 安装时产生的附加用户测试副本；受保护用户的查询被系统拒绝后没有继续访问或绕过。
