# v2026.10.15.1：直接安装的小体积 APK

日期：2026-10-15。本版本保留 v2026.10.14.4 的旋转画布与触控实现，仅优化 APK 打包方式，并更新版本号。

- 原生 `.so` 库和 DEX 代码在 APK 内压缩；合并清单的 `extractNativeLibs` 为 `true`，Android 安装时解压原生库。
- arm64-v8a APK 从 15,220,888 字节减至 6,195,980 字节；armeabi-v7a 从 12,334,642 字节减至 5,258,126 字节。
- 对 APK 解压读取的原生库与已验证构建的 SHA-256 一致，APK 的 ABI 与依赖许可检查通过。
- APK 签名与上一版本一致；Samsung SM-G986U1 覆盖安装成功。原生库压缩构建的应用与独立 `:engine` 进程正常启动，原生 `/serverinfo` 返回 HTTP 200。随后增加 DEX 压缩的最终构建，其代码、资源和原生库与前一构建逐项比对一致，APK 载荷内容不变。
- Release 构建及 Android lint 通过。打包变更未修改串流和输入代码；横屏、B 站全屏及触控实测见 [v2026.10.14.4 验证记录](v2026.10.14.4.md)。

GitHub Release 提供 arm64-v8a 与 armeabi-v7a 的 APK 文件，可下载后直接安装，无需解压 ZIP。
