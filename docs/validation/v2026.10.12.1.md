# v2026.10.12.1 本地发布验证

2026-10-12 在 Windows 本地完成。版本 `v2026.10.12.1`，`versionCode=20261012`；基线为 `v2026.10.11.1`。本记录对应最终原签名包，取代交接包中的云端测试证书和候选哈希。

## 环境与构建

- JDK 17、Gradle 8.5、SDK 34、NDK 27.2.12479018、CMake 3.31.6。
- `:app:assembleRelease :app:testDebugUnitTest :app:lintRelease` 成功。19 个 JVM 测试通过，0 失败/错误/跳过；本地 Release lint 0 错误、24 警告。
- 两种 ABI 的原生 PCM 分包、混合包长、独立客户端广播、有界队列和静音退出测试均在真实设备执行通过。这些控制台测试不播放声音。
- 所有安装均使用覆盖升级，未卸载、未清空应用数据。已有配置和配对保留。

## 真机回归

两台 USB 连接的设备为 Samsung SM-G986U1（Android 13）和 SM-X806C（Android 16，平板），电脑使用 Moonlight。二者分别作为宿主和 Android Moonlight 客户端；声音源仅使用抖音视频/直播，没有播放合成测试音。

| 检查 | 结果 |
| --- | --- |
| 多客户端音频 | 修复前可复现新客户端加入后旧客户端静音；新原生库在手机、平板互换角色后的双客户端测试均有声，用户分别确认平板和手机声音正常；电脑 WASAPI 采样持续有音频 |
| 手机宿主 30/60 FPS 混合 | 连续约 5 分钟，58 次双客户端采样；送帧中位数分别 29.93/59.86 FPS；宿主 PCM 排队最高 20ms，配置上限 40ms；Surface 失败数 0 |
| 多客户端反复重连 | 手机宿主保留平板 60 FPS 客户端，电脑 30 FPS 客户端断开/重连 10 次；宿主和引擎进程保持，电脑每次均有声；平板退出后电脑声音继续 |
| v7a 单客户端断连 | 手机实际运行 v7a，电脑异常退出/重连 10 次；宿主保持，空闲音频停止并清空队列 |
| 最终包静态补帧 | v7a 手机静态页面持续 5 分钟，60 次采样覆盖 296 秒；送帧中位数 59.92 FPS，Surface 失败数 0，PCM 排队最高 20ms |
| 最终包打开 UI / 输入 | 串流中打开 Sunshine 10 次未中断会话；电脑 H.264 720p60、绝对鼠标模式能准确点击手机主页按钮，确认修复引擎进程缺少真实显示尺寸的问题 |
| 最终通用包 / Android 16 宿主 | 平板运行通用包的 arm64-v8a 库，电脑 HEVC 720p60；手机同时以已有 1440p120 设置加入，两个客户端均有声；手机退出后电脑视频、声音继续，宿主和引擎保持 |
| 60/120 FPS 混合短测 | 12 次采样约 55 秒；720p60 送帧中位数 59.84 FPS，1440p120 为 115.61 FPS（105.53–118.64），Surface 失败数 0；不能据此宣称稳定 120 FPS |
| 最终平板宿主断连 | 电脑异常退出/重连 3 次，宿主保持，每次有声，空闲音频停止且队列清空 |
| 电源 / Wi-Fi 锁 | 串流时持有 CPU 唤醒及低延迟 Wi-Fi 锁，最后客户端退出后释放 |
| 编码与签名 | H.264、HEVC 实际串流正常；v7a、v8a、通用包的签名、版本和 ABI 均核对通过；v8a 单独包和通用包均进行过覆盖安装 |

10 次单/双客户端循环验证的是本次相同原生音频库；之后增加 Kotlin 输入尺寸初始化，并重建最终包，补测静态送帧、10 次 UI 打开、输入及 Android 16 宿主双客户端和 3 次断连。

## 结果的边界

本次验证支持断连恢复、多客户端声音和独立帧率调度功能正常。Moonlight 观测期间显示网络丢包 0%，但没有受控弱网对照，不能宣称丢包降低。宿主帧合并和 PCM 溢出是本地缓冲统计，不代表网络丢包。GPU 交接耗时也不是端到端延迟；未测量精确音画同步偏差、跨芯片兼容性或长时间稳定性。

1440p120 混合负载尚未稳定满帧。本次没有实现自适应 FEC 或动态码率。公开记录仅包含汇总，原始设备日志、配对信息和抖音截图留在本地。
