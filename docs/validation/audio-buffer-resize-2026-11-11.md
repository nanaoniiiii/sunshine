# 音频缓冲区调整：实现完成，测试延期

日期：2026-11-11。基线：`ddcf5b5`。本改动保存在 `codex/audio-buffer-20261111` 分支；不包含在 `v2026.11.11.1` 安装包中。

## 问题与改动

运行时此前通过替换整个 PCM 队列来改变容量。已经在旧队列条件变量上等待的读取方，不会随字段替换转移到新队列；旧队列中的数据也直接被丢弃。

现在让生产与读取方始终使用同一个队列，在原有互斥锁内调整底层数组。扩容保留已有的完整立体声帧；缩容保留最新帧，并将容量缩减造成的丢弃量计入统计。调整容量同时改变等待代次并唤醒等待者，使旧代读取结束后重新判断实际状态。相同容量不分配数组、不消耗已排队数据。

会话断开时仍清空音频数据和统计，避免把上一会话样本带入新会话。采集启动、客户端包尺寸扩大和设置修改都调用同一调整入口。
