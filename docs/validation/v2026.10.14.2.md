## 本轮功能

- “设置 → 维护”增加“常见问题”；帮助入口、运行日志与关于栏在设备设置读取失败时仍可访问。
- 原生 Compose 帮助页包含七个可展开主题：全屏、横屏与恢复、Shizuku 下载启动授权、通用设置、厂商差异、掉权／服务停止／发现问题、Sunshine 与 Moonlight 配对。
- 页面有“返回设置”，支持系统返回；返回设置保留原滚动位置，帮助页使用独立可保存状态。
- “关于”显示 `BuildConfig.VERSION_NAME`、项目简介、作者七鬼（nanaoniiiii）及官网／仓库／作者链接。
- 官方 GitHub、Google Play 和 Shizuku 手册均提供入口；本地帮助正文无需联网。
- README 增加官网、下载、帮助入口，真机与官网图，补充安装流程和能力边界；仓库 About 填写官网、简介与主题。

## 构建与真机

执行 `:app:testDebugUnitTest :app:assembleRelease :app:lintRelease`：构建成功；55 项测试、0 失败、0 错误、0 跳过；Lint 0 错误、26 警告。警告数量与基线一致，主要为原有 Android API、清单和本地化检查。

版本 `v2026.10.14.2`，versionCode `20261020`。Release 启用 R8／资源压缩，生成 arm64-v8a、armeabi-v7a 与 universal 三包。使用已有发布签名在 OPPO PDEM10、Android 11 覆盖安装成功，保留应用数据；主页正常显示服务运行。

真机操作确认维护入口、展开收起、Shizuku 正文、通用设置和厂商设置的滚动阅读、系统返回到原设置位置、关于栏版本与链接显示。点击官网后，Android 正确发出 `ACTION_VIEW https://nanaoni.tech` 并进入设备默认浏览器；另在桌面浏览器确认官网可访问。

本轮未重新进行长时间串流、多客户端、32 位设备或全部 OEM 权限测试；旧串流证据明确标注其来源版本，不能当作新版本的全套设备回归。

GitHub 上传大文件时反复中断，因此通用包以 ZIP 提供（约 9.2 MB，原 APK 约 24.5 MB）。ZIP 仅封装原 APK，没有重新打包或重签 APK；解压后按 SHA-256 与原始交付 APK 核对一致。64 位与 32 位包直接提供 APK。发布资源的大小和 GitHub SHA-256 均与本地文件比对。
