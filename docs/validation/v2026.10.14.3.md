- 设置开关、下拉选项修改后自动保存，取消常驻同步提示和底部保存栏。
- 数字输入框在点击 IME“完成”、点击输入框外部或离开页面时提交；失焦后清除光标并收起键盘。编辑中保留草稿，合法数值才写入配置。

- 原有配对证书与设备名称原位迁移，首次启动保存状态备份；现有电脑无需重新配对即可连接。
- 输入任务串行执行，保持按键与修饰键顺序。H.264 按编码器声明能力优先使用 Main／High 配置，以适配接收端硬件解码；诊断提供实际 SPS profile/level。
- README 展示项目能力，统一截图展示尺寸，并将接收端描述为开放的协议生态。

- `:app:assembleRelease :app:testDebugUnitTest :app:lintRelease` 通过；63 项 JVM 测试，无失败。Lint 无错误，保留已有的 28 项警告。
- 两种 ABI APK 和通用 APK 均完成签名验证，沿用此前安装包的签名；支持覆盖安装。

## 实机操作

- HEVC：1280×720、60 FPS，电脑实际显示画面；接收端观测约 60 FPS，丢包显示 0%。
- H.264：同样规格，实际显示手机主页；编码器 `OMX.qcom.video.encoder.avc`，profile 77、level 32，编码约 60 FPS，发送错误、无效输出缓冲与队列丢帧均为 0。
- 鼠标从接收端进入手机设置；键盘通过 Ctrl+A 与数字按键输入 `120`。编辑期间配置仍为 `240`；点击“完成”后配置变为 `120`，键盘和光标消失。
- 输入恢复为 `240`，点击“画面与流畅度”区域后失焦并自动提交，确认配置为 `240`。
- 断开后原生视频会话清空，音频采集停止、缓冲清空；重新连接成功。
- 设置页面上、中、维护／关于区域均通过实际截图检查；常见问题继续位于维护栏。
